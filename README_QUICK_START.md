## 설치 및 실행

### 1. 의존성 설치 (선택사항)

```bash
# 컬러 로그를 위한 colorama (선택)
pip install colorama
```

### 2. 설정 수정

`server_patch_v22.1.py` 파일을 열고 **공인 IP 주소**를 수정:

```python
class ServerConfig:
    AUTH_HOST, AUTH_PORT = "0.0.0.0", 6000
    GAME_IP = "YOUR_PUBLIC_IP_HERE"  # ⚠️ 반드시 수정!
    GAME_HOST, GAME_PORT = "0.0.0.0", 7777
```

**로컬 테스트**만 할 경우:
```python
GAME_IP = "127.0.0.1"
```

**외부 접속** 허용:
```python
GAME_IP = "112.212.253.137"  # 실제 공인 IP
```

### 3. 서버 실행

```bash
python server_patch_v22.1.py
```

## 주요 수정사항 (v22.0 → v22.1)

| 항목 | v22.0 (문제) | v22.1 (수정) |
|------|--------------|--------------|
| **엔디안** | 빅엔디안 (`>`) | ✅ 리틀엔디안 (`<`) |
| **0x8B 패킷** | 빈 패킷 | ✅ 캐릭터 정보 구현 |
| **0x86 좌표** | 모두 0 | ✅ 800×600 타일 시스템 |
| **세션 검증** | 없음 | ✅ 키 검증 추가 |
| **에러 처리** | 부족 | ✅ 타임아웃/버퍼 검증 |

## 문제 해결

### ❌ "세션 키 불일치" 오류

**원인**: `SESSION_STORE`가 초기화되지 않음

**해결**:
```python
# server_patch_v22.1.py 상단에 있는지 확인
SESSION_STORE: Dict[str, int] = {}
```

---

### ❌ 클라이언트가 바로 끊김

**원인**: 엔디안 불일치

**확인**:
```python
# 모든 struct.pack/unpack이 '<'를 사용하는지 확인
struct.pack("<HB", ...)  # ✅ 올바름
struct.pack(">HB", ...)  # ❌ 틀림
```

---

### ❌ 맵 화면이 검은색

**원인**: 좌표가 (0, 0)

**확인**:
```python
# 0x86 패킷 생성 부분
px = 5 * 800 + 400  # 0이 아니어야 함
py = 5 * 600 + 300
```

---

### ❌ 포트 사용 중 오류

**해결**:
```bash
# Linux/Mac
sudo lsof -i :6000
sudo lsof -i :7777
kill -9 [PID]

# Windows
netstat -ano | findstr :6000
taskkill /PID [PID] /F
```

## 리버스 엔지니어링 참고

### 클라이언트 분석 결과

**함수 1**: `sub_4252D0` (UI/시스템)
- 0x8B: 캐릭터 정보
- 0x99: 인벤토리
- 0xA0: 거래 요청
- 0xCD: 다목적 명령
- 0xCE: NPC 정보

**함수 2**: `sub_459790` (월드/엔티티)
- 0x85: 전체 로드
- 0x86: 맵 진입
- 0x89: 캐릭터 스폰
- 0x8D: 몬스터 스폰
- 0xB9: 상점 열기

### 좌표 시스템

```
절대 좌표 = 타일 좌표 × 타일 크기 + 픽셀 오프셋

타일 크기:
  - X축: 800 픽셀
  - Y축: 600 픽셀

예시:
  타일 (5, 5)의 중앙
  = (5×800+400, 5×600+300)
  = (4400, 3300)
```

### 문자열 인코딩

- **인코딩**: EUC-KR (한글 지원)
- **고정 길이**: 21바이트 (NULL 패딩)
- **이름 필드**: 캐릭터/아이템/맵 이름
